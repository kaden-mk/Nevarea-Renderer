## Goals
Nevarea aspires to be a modern, multi-platform renderer that hits the sweet spot between high-level ease and low-level control. The project is being built to handle both PC and console hardware, with the goal of giving developers direct access to the metal for toggling hardware raytracing and platform-specific optimizations. It aims to be a flexible, all-in-one solution, including optional CUDA support for those who need to bake heavy simulations directly into the rendering pipeline. Everything is designed around being as fast and configurable as possible, ensuring the renderer stays out of the way while providing the modern features needed for current hardware.
